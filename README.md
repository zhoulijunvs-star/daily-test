# 一建每日刷题

一级建造师备考每日刷题网页（经济/法规/管理三科）。

## 访问方式

打开 GitHub Pages 链接即可在线刷题（手机/电脑均可）：

```
https://zhoulijunvs-star.github.io/daily-test/
```

> 首次使用需在仓库 Settings → Pages 中开启（Source 选 `main` 分支 / root 目录）。

## 题库

| 科目 | 总题量 | 单选 | 多选 |
|---|---|---|---|
| 法规 | 417 | 321 | 96 |
| 管理 | 624 | 442 | 182 |
| 经济 | 254 | 200 | 54 |

每日按日期顺序滚动抽取 20 题，三科轮换覆盖不重复。

## 更新方式

本地运行 `gen_quiz.py` 生成最新 `quiz/quiz.html`，复制为 `index.html` 推送到本仓库即可。
